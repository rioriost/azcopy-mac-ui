# azcopy-mac-ui 0.2.1

This release addresses the design and code review recorded in
[`docs/design-code-review-2026-09-16.md`](../design-code-review-2026-09-16.md).

- Honor nonrecursive sync and reject additional flags that override safety settings.
- Stream stdout/stderr without pipe deadlocks, display authentication instructions before exit, and support cancellation.
- Remove credentials from persisted URLs, migrate old preferences, and redact both forms of SAS arguments.
- Preserve command results separately from preview validation and confirm destructive command snapshots.
- Parse quoted additional flag values without invoking a shell.
- Provide an explicit Sign In workflow and reject unsupported managed identity Object IDs.
- Enforce HTTPS consistently and correct line-coverage and release preflight gates.
- Persist nonsecret release credential references per checkout, diagnose Keychain
  access separately from missing configuration, and preserve previous artifacts on retries.

URL query strings and additional flags are no longer restored on launch. Re-enter SAS
credentials and any additional flags before running a transfer. Existing managed
identity Object IDs must be replaced with the appropriate client ID or resource ID.

macOS 14 or newer and Apple Silicon remain required. AzCopy is provided by Homebrew,
not bundled with the app.

The arm64 release archive is Developer ID signed, notarized by Apple, stapled, and
Gatekeeper-assessed. SHA-256 is provided alongside the ZIP.
