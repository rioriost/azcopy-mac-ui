# azcopy-mac-ui 0.2.2

This release improves the native macOS operation forms and adds repeatable
compatibility checks for AzCopy 10.32.8.

- Use grouped, resizable forms with aligned fields and clearly named controls.
- Keep the command preview and primary action visible while options scroll.
- Distinguish dry-run actions with a Preview label and an explicit no-change message.
- Open the standard Settings window with ⌘, and run the selected operation from
  the Operation menu or with ⌘Return. Escape cancels a running command.
- Improve status cues, empty logs, secure-field labels and keyboard navigation.
- Load Azure CLI tenants only when requested with Load tenants.
- Verify all 15 operation command surfaces and supported sign-in flags against
  AzCopy 10.32.8. Add optional local Azurite integration tests for actual SAS Blob
  upload/download, filtering, sync, metadata, job inspection, removal and dry runs.

Validation: 101 offline Swift tests, 66 script tests and 3 installed-AzCopy
integration tests passed. Core line coverage remains 96.06%. GUI checks include
normal/minimum window sizes, Light/Dark appearance, keyboard operation, running
and cancelled states, and destructive confirmation cancellation.

Cloud authentication, real Azure transfers, Azure Files, ADLS, benchmarks and
interrupted-job resume are not qualified by the local Blob tests. Runtime UI
checks were performed on macOS 27.0; macOS 14 remains the minimum deployment target
but was not available for runtime testing. VoiceOver speech was not tested.

Apple Silicon and Homebrew AzCopy remain required; AzCopy is not bundled.
